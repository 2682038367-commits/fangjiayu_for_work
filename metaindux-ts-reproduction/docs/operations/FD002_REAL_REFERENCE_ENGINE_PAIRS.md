# FD002低RUL：相对真实训练预测器的逐台配对

Scope `scope-20261106-fd002-real-reference-engine-pairs`，diagnostic/supporting。用户明确要求仅做一次逐台配对，复用相同259台测试发动机末端窗口及标签的现有预测，不训练。

- [Code] 源为现有正式逐发动机预测CSV：共同5生成器种子3/13/23/33/43各5预测器，加真实数据训练的5预测器。先核验全部259台窗口身份来源、标签、相同预测器seed配对和原正式RMSE，再取0-30的61台、31-60的41台。
- [Code] 每发动机/生成种子只比较两量：A=mean_e(生成训练预测−真实训练预测)；D=mean_e(生成预测−真实标签)²−mean_e(真实训练预测−真实标签)²。平方先在每个预测器上计算，不能先平均预测再平方。A>0只是比参照报高，不保证高于真实寿命；D>0表示更差。
- [Code] 汇总A/D均值及中位数、两者正号计数和同发动机跨生成种子重合。共同组事先固定用户点名3/23/33，另列23/43与全部5组。按>0描述，不做新显著性检验或阈值筛选。
- [Code] 集中度预定为最大的5个正D之和/全部正D之和，分母不包含负D改善，且报告正、负及净总量；保留所有发动机，不删异常点后重写总体。病例ID仅用于定位，不能据正式测试调轮次/阈值。
- [Hypothesis] 若共同0-30额外错误存在，可建议下一次回训练/dev检查；若31-60主要少数种子或发动机，要保留局部解释。配对本身不能证明传感器或标签原因。

预算一次只读统计；本轮不新增传感器检查、邻域搜索、模型训练、采样或推理。生成器统计单位仍5次，预测器重复不增加生成器样本量。完成表/集中度图/限定结论后停止，严格main/A/B不变、C推迟。执行`.venv/bin/python analysis/diagnostics/fd002_real_reference_engine_pairs.py`。
