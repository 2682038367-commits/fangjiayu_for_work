# FD002 seed43：进一步区分训练、采样和判别评价的波动

Scope `scope-20261105-fd002-seed43-variation-stages`；diagnostic/supporting。用户“那不能进一步验证吗”授权继续检查既有seed43判别差距。已说明约2–2.5小时，不训练下游预测器。沿用paper-reproduction流程，严格main/A/B结论不变、C推迟；其他数据集与125组分析继续暂停。

- [Observed] 先前实际CUDA核跟踪显示原生模式卷积路径不同；固定设置后首批779操作和两次完整70轮训练记录一致。历史第67轮与旧原生重跑第67轮的共同条件、实际噪声、native采样分数均值分别.434124和.178009。固定训练的第67轮为.241707。训练重复已验证，采样/判别重复和旧权重共同固定采样对照尚缺。
- [Hypothesis] 历史差距至少部分由训练所得权重差异承载；共同固定采样和可重复判别若仍保留差距，可以缩小采样/评价解释。无法恢复不存在的历史中间状态，不能声称百分百重建旧训练。

预先固定三个分开的对照，各自只改一个因素：

1. **训练阶段**：复用上轮完整训练记录器，复制并只替换卷积flags/assert和日志标签，原生`benchmark=True/deterministic=False`独立运行两次70轮/11410更新。与上轮固定设置两次对照，检查初始参数、全部顺序、置零抽签、损失、参数/优化器/RNG状态与best/67/70。数据、网络、训练随机种子43、原超参数不变。原生两次相同也按实报告，不增加重复找分叉。
2. **采样阶段**：固定两个已经存在的第67轮权重A（最早历史训练）与B（20261102原生重跑），全部使用`benchmark=False/deterministic=True`。原生采样的旧分数仅作背景。三批依次为A、A重复、B；A重复只检查固定采样的重复性。每批41539窗口、同样RUL顺序、sampling103、DDPM1000/CFG3、关闭条件分支随机丢弃但仍消费旧随机抽签，显式无条件分支不变。实际每个噪声张量对独立旧序列生成器校验，并与既有anchor起止/全序列指纹一致。A与A重复必须逐元素完全相同；不一致则停止B，不自动修改配置。
3. **评价阶段**：对A与其逐元素一致的重复批次分别做同样5个判别器种子3/13/23/33/43、相同冻结切分；比较五个分数是否逐个一致。随后对B做同样5次。旧权重差距筛查预定为均值绝对差至少.03且至少4/5方向一致，只是描述性诊断，不是五次独立生成器训练的统计检验。

结论分支：

- 原生两次分叉、固定两次一致且随机输入记录匹配：加强当前完整训练计算路径归因。
- A重复采样不一致：采样数值变动仍未隔离，停止B，不能把剩余分数变化全部归给权重。
- A数组完全一致、判别分数不一致：评价仍有变动，先报告，不选择有利分数或补跑。
- 采样/评价重复均通过、A与B差距保留：直接支持旧权重本身带来可区分性差距。
- 差距消失或明显缩小：原生采样路径可能贡献历史差距；不能继续默认全部来自训练。

预算恰为2次生成器训练、至多3批完整生成、15次判别器拟合；零下游预测器拟合，不评价新增原生训练的生成指标，不扩展种子或逐轮选择。不改默认源文件；冻结输入/代码哈希，独立进程、记录实际flags；全局strict=False以保留原median，TF32等其他设置不变。失败保留并停止，不自动重试。
