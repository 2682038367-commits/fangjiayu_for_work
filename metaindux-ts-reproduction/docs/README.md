# Documentation and frozen conclusions

- `conclusions/final/`: final reports supporting the frozen result record.
- `figures/theta/`: threshold-analysis figures and interactive reports.
- `provenance/`: the supplied handoff and its manifest, retained as source
  provenance after its useful contents were integrated into this project.
- `operations/`: execution prerequisites retained for reproducibility.

For numerical claims, `results/frozen_numbers.json` is authoritative.
