结论先行：上一轮我从 θ 分布推断"公开臂 θ₂ 偏高、丢弃过多频率，所以性能差"， 并预注册了一个可证伪的预测。实测数据把这个预测否决了，而且是反向否决—— θ₂ 最低的 seed 53（0.049）拿到了 7 个种子里最差的 RMSE 35.30， θ₂ 最高的 seed 13（0.496）拿到了最好的 23.54。 θ₂ 与 RMSE 呈负相关（ρ=−0.64，p=0.14，不显著），且在四个数据集上符号不一致。 所以：θ 不能解释公开臂的跨种子方差，那个"机制解释"要撤回。

为什么 n 小也能下这个判断：不是因为某个 p 值够小，而是因为方向不自洽。 若 θ 真有稳定效应，符号至少应该一致，哪怕不显著。

4. 需要修正我上一轮的建议

上一轮我说"固定 0.25 比公开代码好，可以作独立第二臂"。用可配对的数据认真检验后（n=3）：

配对差（固定 − 公开）= +0.42, −2.10, −0.73，均值 −0.80，SD 1.26

唯一已经站得住的、关于固定 0.25 的正面结论仍然是"它把跨种子方差压下去了" （SD 1.26 / 3.97 这个量级的差异，如果有更多种子支持的话），但这需要补跑才能定。

5. 意外收获：可学习臂里有一个方向一致的强信号

公开臂的 θ 没有效应，但两个可学习臂的 θ₁ 与 RMSE 都是强正相关，方向一致：

臂nρ(θ₁, RMSE)置换 pρ(θ₂, RMSE)
soft7+0.8930.012+0.429 (p=0.35)
binary-STE7+0.8570.024+0.036 (p=0.96)

读法：θ₁ 学得越大（丢弃越多频率）→ RMSE 越差。soft 臂里从"丢弃 18%"到"丢弃 56%"，RMSE 从 24.64 涨到 31.57。 两个独立实现的臂给出同一个方向，比单个 p=0.012 更值得信。

这顺带解释了"可学习臂为什么不如固定 0.25"：不是"可学习"这个机制错， 而是它学到的 θ₁ 散布在 0.18–0.56，而这个区间里偏大的一侧明显有害。固定 0.25 恰好把这个散布压住了。
