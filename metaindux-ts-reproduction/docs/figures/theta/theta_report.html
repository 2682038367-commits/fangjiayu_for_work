2. 四条站得住的结论

确认① θ 由 seed 唯一决定，与数据集无关。

FD001 / FD002 / FD003 / FD004 的 seed 3、13、23、33、43 读出完全相同的两组值（小数点后 16 位一致）。 说明 θ 的随机初始化发生在数据加载之前、且共享同一条 RNG 序列。 这条是可复现性的硬证据：任何人都能用 seed 复现我们的 θ，直接写进论文附录。

发现② θ₂ 系统性贴近上界——这是唯一真实的系统性偏差。

7 个种子里 5 个 θ₂ ≥ 0.4167（上界 0.5 的 83%），前 5 个种子全部 >0.41。 θ₂ 均值 0.370，比理论均值 0.25 高 48%，比我们选定的固定值 0.25 高 48%。

机制含义：公开臂的第二个频率模块丢弃 42–50% 的频率，而固定臂只丢弃 25%。 按"θ 是结构开关"的理解，θ₂ 越大 → 支路越稀疏 → 主路与支路的信息重叠越少， 但也意味着支路本身携带的信息被过度削减。这正好对应公开臂 RMSE 28.295 / SD 0.1856 不如固定 0.25 的 26.245 / 0.0989。

克制的反面 但整体分布并不异常，不能声称"作者代码抽到了坏值"。

把 14 个 θ 合并做 KS 检验：D = 0.2613, p = 0.248 —— 无法拒绝 U(0,0.5)。 7 个种子的样本量下，"5 个偏高"完全在随机波动范围内。

而且 seed 53 / 63 的 θ₂ 只有 0.0488 / 0.1864，比我们的固定 0.25 还低。 这两个种子是天然的对照点（见第 4 节的可证伪预测）。

发现③ 可学习臂的 θ 跑出合法区间，学到的是一组退化解。

公开臂的 θ 永远落在 (0, 0.5) 内；soft / binary‑STE 臂的 θ 落到 [−4.33, +1.08]。 θ 必须属于 [0,1] 才能喂给 torch.quantile，所以这些值必定经过了 前向 clamp 或 sigmoid 参数化。两种解释下等效丢弃比例都趋近 0：

4. 关键检验：一个可以证伪"θ 是主因"的预测

现在只差每一步就能把 θ 从"嫌疑"变成"证据"或"排除"。预测如下：

  • 若"θ₂ 偏大 → 性能变差"成立，则 seed 53（θ₂=0.049）和 seed 63（θ₂=0.186） 的 RMSE 应明显优于 seed 23（0.496）、seed 13（0.496）、seed 3（0.488）。
  • 若 seed 53 / 63 的 RMSE 并没有更好（甚至更差），则 θ 就不是 FD002 跨种子方差的主因， 剩余方差必须归给其他随机源（权重初始化、数据顺序、扩散采样的 latent 噪声）—— 这会直接改变论文里那一段的归因写法。

这需要逐种子的 RMSE / DS，目前只有汇总值（28.295 ± 0.1856），无法做。

推论性旁证：lr_constant 臂（seed 13/23/43）读出的 θ 与公开臂逐位相同。 即"只换学习率调度"时 θ 向量完全不变。所以两臂若性能不同，差异必然来自 θ 以外的因素。 这是一条已经到手的、支持"θ 不是唯一方差源"的对照。

6. 不影响结论的三件事

  • θ 未被 metadata 记录——已绕开，直接从权重读，现在拿到全部 40 个文件的值。 建议后续训练脚本顺手把 threshold_param.item() 写进 metrics json。
  • n=5 的 θ–epoch 相关不显著（θ₁: ρ=−0.50, p=0.45）。方向"θ₁ 越小 → 需要越多 epoch" 只在 seed 23（θ₁=0.074, epoch=68）一个点上成立，不要写进报告。
  • 窗口 24/96 与继续堆种子仍建议搁置，先把这个散点做完——它能一次性决定 θ 在归因里的权重。

统计口径：KS 检验用 scipy 单样本检验；相关系数用 Spearman，p 值用精确置换检验 （n≤8 时穷举全部 n! 种排列）。n=5 时双尾可达的最小 p = 2/120 = 0.017（且需 |ρ|=1）， 所以 ρ=−0.5 对应 p=0.45 属预期，不是计算错误。
