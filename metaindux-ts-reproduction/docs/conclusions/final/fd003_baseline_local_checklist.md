# FD003 baseline 诊断・本机执行清单

**目的**：区分 FD003 上 RMSE 偏离论文 4.511（z = 8.25）的两种归因——
生成端数据质量 vs 评估协议本身的能力上限。

**原理**：现有主结果是 TSTR（合成数据训练 → 真实测试集评估）。
baseline 是 TRTR（**真实训练数据**训练 → 同一真实测试集评估）。
除"训练数据从哪来"外一切冻结，两者的差有且只有一个来源：数据本身。

---

## 第 0 步：核对数据量（先做，决定后续是否需要额外补跑）

```python
print(X_real.shape[0], X_synth.shape[0])
```

参考比例：FD001 = 100 台发动机 → 15931 个窗口（约 159/台）。

| 情况 | 处理 |
|---|---|
| 两者量级相当 | 直接进入第 1 步 |
| 真实窗口明显更少 | **必须补做**：从合成数据中随机抽等量子集重跑一次，否则 baseline 偏低只是数据量效应 |

---

## 第 1 步：唯一变量

**换**：训练数据来源（合成 → 真实训练窗口）
**不换**：以下每一项都必须与主结果逐位相同

- [ ] 预测器架构（同一个网络定义）
- [ ] MinMaxScaler（同一个、仅用训练集拟合的那个）
- [ ] 划分方式：论文 70/30，同一 split seed
- [ ] 训练超参：optimizer / lr / epoch / batch size 全部不变
- [ ] 测试集：FD003 每台发动机最后窗口 + 真实 RUL，与主结果逐条一致
- [ ] 评估器种子：同样的 5 个

**禁止**：因真实数据上过拟合更早出现而加 early stopping、减 epoch、改学习率。
一旦改动，对照组失效。波动大就如实记录。

---

## 第 2 步：统计口径（关键，不可省）

baseline **必须跑满 5 个评估器种子**，报均值 ± SD。

```
本地合成版   20.717 ± 1.223   (SEM 0.547, n=5 生成种子)
baseline     X      ± ?       (同样的 5 个评估器种子)
```

单点估计无法与带 SD 的分布比较——只跑一次得出的
"接近 20 还是接近 16"没有统计效力。

---

## 第 3 步：读数

已知锚点：**论文 16.206** / **本地合成版 20.717**

| baseline X | 判断 | 归因 | 下一步动作 |
|---|---|---|---|
| ≈ 20.7 | 给真实数据，RMSE 仍是 20.7 | 协议地板即瓶颈，生成端无罪 | 查预测器架构 / 划分方式 / 预处理与作者的差异 |
| ≈ 16.2 | 同一套协议用真实数据能到论文水平 | 协议无碍，生成端确为瓶颈 | 集中查扩散训练质量 |
| 落在中间 | 两段分摊 | `X − 16.206` 归协议<br>`20.717 − X` 归生成端 | 按比例分配后续精力 |
| 明显 < 16.206 | 本地协议强于论文口径 | 生成端差距比表面 4.511 更大 | 两端都要查 |

附带可能性：若 X ≈ 20.7，这是**反常**结果——真实数据通常优于合成数据。
正因其反常，它才是信息量最大的结局。
