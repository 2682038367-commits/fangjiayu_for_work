# 0标签混用：单因素验证结果

日期：2026-10-23。Run ID：`diagnostic-zero-label-pair-fd001-seed3-20261023`。

## 结论

**[Observed]** 本次FD001、生成种子3的当前环境配对干预，明确支持“整批RUL随机置零会造成RUL=0条件异常”的解释。禁用该分支后，0标签的代理预测一致性恢复到接近0的水平，且满足事前判据；这不是所有条件失效，也不证明全部数据集的物理生成或下游预测问题都已修复。

## 单因素与完整性

- **[Code]** 唯一实验因素为`batch_label_zero_prob`从0.1变为0。两组在当前环境重新训练FD001 full-data w48 seed3，各70epoch、batch256、T1000 linear DDPM，模型、内部null embedding/dropout、Adam、调度、best-loss选择和完整采样标签保持一致。禁用时仍保留原来的NumPy随机抽样，避免额外改变随机流。
- **[Observed]** 两组均complete，原版用时875.1秒、禁用版856.6秒，全部流程于2026-10-23 10:17:26 +08:00结束。本次仅2个生成器，每组由同一5个已有真实训练预测器评估。
- **[Observed]** 配置/源码/输入哈希全部匹配快照，两个训练loss均70行且有限，生成数据均15931×48×14且有限，条件标签完全相同；对保存的5×15931预测重新计算结果一致。审计`audit.json`无错误。初次监督进程日志编码失败发生在训练之前，修复后才正式运行，已记录于快照。
- **[Observed]** 原作者分支和默认值仍为0.1；禁用版使用独立配置与产物后缀，没有覆盖历史严格复现产物。

## 原因解释与边界

- **[Code]** 原训练循环把约10%批次的所有真实寿命条件替换为0，传感器数据不变，因此0会同时对应真实失效和非失效窗口；网络另有独立null条件表示。
- **[Observed]** 本次仅去除数值0的混用，即显著减少RUL=0代理误差，构成比前一轮描述统计更直接的单因素支持。
- **[Hypothesis]** “0条件被当成生命周期混合条件”与代码路径、原版预测分布以及干预结果一致，但尚未跨生成种子或跨数据集检验可重复性，也没有直接验证物理失效特征。
- **[Observed]** 本报告指标是“真实训练预测器判断生成样本与条件的一致性”。没有用新合成数据重训下游预测器，也没有计算新的真实测试集预测结果；不能将10.151→7.926当成原TableI真实测试RMSE改善。
- **[Observed]** 固定生成种子3的一次配对不能估计生成种子间方差，不能给出跨种子置信区间。论文无此干预指标，因此无法提供对应论文差距；本地判据通过不改变原严格复现结论。
