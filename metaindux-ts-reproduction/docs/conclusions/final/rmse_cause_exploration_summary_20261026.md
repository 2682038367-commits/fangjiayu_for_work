# 高RMSE原因探索阶段总结（2026-10-26）

## 已验证

- [Code] 作者公开训练代码含约10%整batch标签置零，同时网络另有null条件机制。公开来源证据见docs/provenance/author_label_zeroing/。
- [Observed] 同种子3当前环境单因素对照支持局部RUL0混用解释：FD001RUL0代理RMSE79.412→2.623，FD00292.551→5.451。但整体代理RMSE：FD00110.151→7.926，FD00216.442→19.289；非零段FD0017.991→7.948，FD00214.768→19.345。不能默认全局采用该修改。
- [Observed] 以上是固定真实训练预测器对生成样本的标签一致性，不是重训下游预测器后的真实测试RMSE。两套干预均仅一个生成种子，无多生成种子因果功效。

## 较强线索但非唯一归因

- [Observed] FD00331–60的21台真实测试发动机：水平支持距离差与合成训练额外MSE的Spearmanρ=.862；最近1个邻居.819，放宽标签池.760，五生成种子关联方向一致。整体中位支持距离未明显变差，问题集中在部分局部个体，不是整段缺失。
- [Observed] FD004高RUL多数组合水平近邻距离偏大，但误差解释较弱：91–124ρ.245且1NN降.022，125ρ.416且1NN.284；某些难例真实训练基线同样或更差。
- [Hypothesis] 信号位置偏移、缺少局部真实变化/发动机类型和预测器优化均可能有贡献。距离不能唯一分辨三者，工况混合机制也未因果验证。

## 目前缺乏支持/不能成立的简化说法

- [Observed] 平均窗口差分幅度接近真实，未见严重整体过平滑；线性/短时滞同步差异总体接近真实参照，局部例外保留。不能据此优先确定原型引导或普遍跨通道修复。
- [Observed] 固定真实预测器通常可以读出生成条件，FD003尤其明显；不支持全局条件塌缩。低代理误差不代表真实变化覆盖充分。
- [Code] 测试目标与训练标签同样截断125，因此不能用“预测不到原始RUL200”解释目标125下的误差；标签合并可能影响条件复杂度，但不是算术上的必然误差。
- [Observed] FD003/4长寿命窗口更多属实，但尚未证明其比例导致高RMSE；真实/合成方向的预测效用不对称。
