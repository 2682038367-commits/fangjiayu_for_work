# FD003预测器：生成数据拟合与真实数据迁移

Run ID：`diagnostic-fd003-predictor-fit-20261026`；scope：diagnostic/supporting；日期2026-10-26。用户授权继续检查生成train/dev和真实test分段误差。本轮仅CPU推理，无模型训练、参数调整或零标签修复实验。

## 主要结论

**[Observed]** FD003原全数据w48的25个预测器，在RUL31–60生成训练集和生成验证集上的RMSE分别8.825和8.827，真实测试集29.466。按真实测试集的逐整数RUL直方图重新加权后，生成train/dev分别9.271和9.337，差距仍然明显。5个生成种子都出现生成dev显著低于真实数据误差的现象，不是单一生成种子的结果。

**[Hypothesis]** 相比“主要因为预测器没拟合生成训练数据”，这些结果更支持“在生成数据上学到的关系迁移到真实信号时存在差异”。这不是缺覆盖、信号偏移或优化问题的唯一归因；生成数据可能比真实数据容易，真实任务也存在同样预测器难以拟合的部分。

## 样本、模型及统计单位

- **[Observed]** 主分析25个历史预测器：生成种子3/13/23/33/43，各5个评估种子。原生成数据20020窗口，train14014、dev6006，窗口48×14、末端RUL截断125。RUL31–60共有train2098、dev902窗口；真实测试该段21台发动机，每台只取最后一个窗口。
- **[Observed]** 额外复用5个真实数据训练预测器和10个既有固定35epoch真实锚点/control预测器，共读取40个权重文件。不是40次新训练，也不是40个独立重复。5个anchor-control与历史generationseed3对应模型在所有保存预测上完全一致，最大差为0，不将其当作独立证据。
- **[Code]** 预测器固定为原LSTM：14输入、28循环隐藏单元，展开48步后接64单元全连接层；输出连续RUL，不裁剪到0–125。使用原保存的最优dev权重，不选新检查点。
- **[Observed]** 本报告主表RMSE为所有相应模型/样本平方误差平均后开方，不是先平均预测值的集成结果，也不是逐模型RMSE的算术平均。原结果亦保留`mean_model_rmse`供对照；例如目标段前者29.466，后者29.260，二者不能混用。

**[Observed]** 目标测试段平均真实RUL49.143，生成训练预测器平均高估18.544，相当于平均预测67.687；其生成dev偏差只有+2.433，重加权后+2.539。真实训练预测器在同一测试段也高估12.341。

**[Hypothesis]** 真实训练来源窗口已经出现较大差距，削弱“只有官方测试发动机恰好分布特殊”这一单独解释；但不能据此证明生成器缺失哪种故障类型，也不能把条件内难度差异视为已排除。

**[Hypothesis]** 真实锚点虽然实际参与训练，其拟合误差仍高于生成训练窗口；这与少量真实内容没有充分影响训练目标相容。209个锚点只占全部训练窗口1.49%，但本轮没有单独改变它们的损失贡献，不能证明优化权重不足是原因。真实信号复杂性、与生成关系不一致、当前模型能力等也都相容。

## 验证与边界

- **[Observed]** 40个权重的真实test预测均通过历史输出复算，最大逐预测差6.10e-5，低于预设1e-3。输入、源码和权重哈希一致；从保存的逐样本预测独立重算1180行分段结果及逐RUL匹配结果，最大MSE差2.28e-13。
- **[Observed]** 真实train/dev均覆盖相同100台训练发动机，存在相邻重叠窗口跨划分，因此真实dev不能作为按发动机独立的泛化验证。小生成train/dev差也不等于生成信号覆盖真实变化。
- **[Observed]** 该诊断评估最优保存权重，不是最后一轮或每个epoch的完整轨迹；不能据此证明训练已达到最优、继续训练一定无效或预测器没有能力上限问题。
- **[Observed]** 精确RUL重加权仅控制标签构成，不控制故障模式、传感器分布和条件内难度。生成误差低、真实误差高是迁移差异的证据，不能唯一区分缺了一类与这一类信号整体偏移。

## 当前决策与停止

**[Hypothesis]** 当前优先级：生成到真实的条件内信号/支持差异高于“单纯没有拟合生成train”；真实任务难度、模型能力及对少量真实锚点的利用仍未解决。停止把距离优化或盲目加训练轮数作为默认下一步。

**[Hypothesis]** 若用户继续授权训练，建议最小单因素对照是固定已有209锚点、RUL直方图、数据划分、35epoch更新数和评估种子，仅改变真实锚点的训练损失权重，检查真实31–60误差及其他段退化。这是EXT-001的新配置，需要冻结权重与预算后执行；本轮未启动。它测试锚点利用的实用效果，仍不能唯一定位生成器机制。另一选择是先继续只读定位同RUL的传感器残差，信息增益与现有覆盖诊断重叠。

**[Observed]** 本轮40个既有权重推理检查完成后停止；无新训练或参数扫描，零标签路线仍暂停。Scope为`scope-20261026-fd003-predictor-fit`，diagnostic/supporting；严格main/A/B历史结论不变，C继续延后。

**[Observed]** 五段式：当前31–60生成train/dev8.83/8.83、真实test29.47→论文无此拟合/迁移诊断目标→论文数值差距不适用→5生成种子方向一致，但不是单因素因果实验→不改变原严格复现结论。
