## 结论

**[Observed]** 20/20次下游预测器训练完成，原始预测与全部分段指标复算通过。FD001真实测试整体RMSE改善，FD002反而变差。0标签修复没有表现为统一的真实测试收益；不能直接作为四数据集的默认性能修复。

## 固定协议与完整性

- **[Observed]** 复用已有FD001/FD002 generation seed3原版prob0.1与禁用批量置零prob0数据，共4份；每份训练5个下游预测器，评估种子3/13/23/33/43配对，共20次。没有重新训练生成器、运行判别器或增加生成数据。
- **[Code]** 沿用原全数据w48评估协议：每FD原固定synthetic70/30索引、35epoch上限、单层LSTM hidden64、Adam lr0.002、原调度及best-dev权重选择、训练batch256。真实测试发动机与原评估完全相同；RUL标签截断125，预测输出不截断。
- **[Observed]** 开始2026-10-26 15:34:03 +08，结束15:40:25 +08，约6分22秒。所有输入/源码哈希不变；20份权重存在，每模型原始测试RMSE与保存权重复算一致；100台FD001、259台FD002的逐发动机预测均保存。
- **[Code]** 原评估器训练过程中会记录真实测试指标，但权重按合成dev误差选择；本轮保留此原始行为，没有按测试指标挑权重、挑种子或调整配置。

## 分段真实测试RMSE

**[Observed]** 每格为“原版 → 禁用版”，按真实测试的截断标签分组；取5个预测器的RMSE均值，与原总体表口径一致。另保存pooled RMSE以便按MSE分解。

| 真实RUL区间 | FD001 | FD002 |
|---|---:|---:|
| 0-30 | 11.176 → 6.731 | 23.383 → 26.597 |
| 31-60 | 13.809 → 11.788 | 21.637 → 18.159 |
| 61-90 | 25.230 → 21.901 | 19.773 → 19.301 |
| 91-124 | 15.136 → 15.633 | 25.892 → 29.094 |
| 125 | 10.841 → 14.307 | 30.786 → 37.208 |

- **[Observed] FD001**：0–90阶段改善，尤其0–30；125段从10.841升到14.307，91–124轻微退步。整体收益并非覆盖所有寿命阶段。实际测试窗口没有RUL=0，低阶段收益是修复训练数据后传递到其他真实窗口的结果，而不是直接评价RUL=0样本。
- **[Observed] FD002**：31–60、61–90改善，但0–30、91–124和125变差。125段增加6.422，且该段有57台发动机，明显影响整体结果。

## 与代理条件一致性的关系

- **[Observed]** 先前固定真实预测器对生成窗口的检查中，RUL=0两数据集均显著修复；这件事与本轮“用生成窗口训练新预测器，再评估真实窗口”是不同方向。
- **[Observed]** FD002的125条件生成窗口代理RMSE曾从12.809改善到11.002，但本轮新训练预测器对真实125窗口RMSE反而30.786→37.208。这说明“条件更容易被读出”不能代替“训练数据对真实任务更有用”。
- **[Hypothesis]** 禁用标签混用可能同时改变其他条件的生成分布、覆盖或下游学习关系；本轮没有区分这些中间机制，不能把FD002退步唯一归因于其中之一。

## 范围、停止与建议

- **[Observed]** 本轮支持“收益依数据集/寿命阶段而异”，不支持将禁用置零直接推广为通用性能修复。原作者默认prob0.1和历史严格结果均保留；修复版独立标记。
- **[Observed]** 范围`scope-20261026-zero-label-downstream` diagnostic/supporting已完成，预算20次已满，无自动后续训练。新诊断没有论文对应的干预目标，因此不能将本结果代替原TableI或重新宣称论文数值复现。
- **[Observed]** 五段式：本地配对结果已测 → 论文无对应修复结果 → 同指标干预差距不可比 → 仅评估种子变化可估计、生成变化未知 → 不改变原严格论文结论。
- **[Hypothesis] 建议**：保留此单种子结论，先定位FD002修复版91–125的信号分布/支持与原版的差异，再决定是否补其他生成种子。若目标是提升总体真实测试RMSE，不能仅以0标签代理指标作为模型选择标准。不要马上重跑四数据集或同时改多个机制。
