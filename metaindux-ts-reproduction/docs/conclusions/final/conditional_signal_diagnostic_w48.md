# 全数据 w48：RUL匹配的信号诊断

日期：2026-10-22；Run ID：`diagnostic-conditional-signal-w48-20261022`。Scope：diagnostic / supporting，用户明确要求分析现有产物。

## 结论

**[Observed]** 本轮最明确的是相同RUL条件下的传感器水平分布存在偏移，以及跨RUL的均值差异幅度与真实数据不一致。未见平均意义上的严重过平滑，未见整体跨通道线性同步关系普遍崩溃，也未见均值特征上的寿命条件完全失效。上述结论不排除个别传感器、瞬态事件或高阶依赖存在问题。

## 设计、口径与来源

- **[Code]** 输入为既有全数据w48真实训练窗口与`outputs/FD00*_w48_seed{3,13,23,33,43}.npz`，共20份合成数据。FD002为共同5种子诊断，不是其7种子headline的替换。
- **[Observed]** 全部20份合成标签与真实训练窗口标签逐项相同，shape核对通过。每数据集/种子/区间选择600个窗口，区间0–30、31–60、61–90、91–124、125。Real A与Real B来自互不重叠的发动机集合，按每个整数RUL精确匹配采样；合成样本匹配同一整数标签序列。每个种子重新确定真实发动机二分及抽样，记录全部索引。
- **[Observed]** Real B vs Real A是本地不同真实发动机之间的描述性参照，不是统计显著性阈值、物理真值或零误差基线。真实与合成数据没有逐窗口物理对应关系，不计算逐点生成重建误差。
- **[Code]** 使用原作者MinMax处理后的传感器值；为比较不同传感器，诊断中再除以该传感器全部训练记录的标准差。此操作仅确定分析单位，没有改变训练、模型输入或工况标准化流程。
- **[Observed]** 指标对14传感器、5区间等权汇总，再平均5个种子/参照划分。不按原始样本比例加权，避免RUL=125的样本堆积支配诊断。种子间变化同时包含生成差异、发动机参照分组差异和抽样差异，不能当作纯生成方差。
- **[Observed]** 仅控制RUL，没有按运行工况setting或故障模式匹配；生成数据没有额外输出这些标签。不同工况/故障混合可能影响这些统计解释，特别是单个传感器全局标准差较大的数据集。

## 1. 相同RUL区间内的传感器水平分布

**[Observed]** 对每个窗口取48步的传感器均值，计算真实/合成的Wasserstein距离，再跨14传感器平均。单位为对应真实训练传感器标准差。数值只适合在同数据集内与真实参照比较，不宜据跨数据集大小排序生成质量。

| 数据集 | 生成vs真实 | 真实B vs真实A | 生成距离更大的区间×种子数 |
|---|---:|---:|---:|
| FD001 | 0.216 | 0.093 | 23/25 |
| FD002 | 0.037 | 0.020 | 23/25 |
| FD003 | 0.207 | 0.130 | 20/25 |
| FD004 | 0.035 | 0.019 | 24/25 |

**[Observed]** 四数据集都存在同RUL的水平分布偏移；FD003的0–30段平均距离0.342，真实参照0.166；FD004对应0.052 vs0.023。它们不能直接归因于前面分段预测误差，因为这是训练窗口信号统计，而前一轮使用真实测试发动机的预测误差。

## 2. 窗口内波动与过平滑

**[Observed]** 一阶差分RMS表示相邻周期变化幅度；二阶差分RMS表示局部曲率/快速变化幅度。先按传感器标准差统一单位，再汇总。比值=生成/真实，1表示同等平均幅度。另检查去窗口均值后的频谱中≥0.25 cycles/sample部分的能量比例。

| 数据集 | 窗口内SD比 | 一阶差分RMS比 | 二阶差分RMS比 | 高频占比差（百分点） |
|---|---:|---:|---:|---:|
| FD001 | 0.968 | 0.973 | 0.972 | +0.287 |
| FD002 | 0.989 | 0.986 | 0.985 | -0.609 |
| FD003 | 0.976 | 0.972 | 0.972 | -0.053 |
| FD004 | 0.989 | 0.989 | 0.991 | +0.051 |

- **[Observed]** 平均一阶/二阶变化幅度仅低约1%–3%，没有严重整体平滑的信号。FD003局部传感器仍有差异，例如s9平均一阶差分比0.913、s14为0.923；不能把平均接近1等同于每个通道或每个事件保真。
- **[Observed]** 这些是固定48步窗口的汇总特征，不是专门的突变/拐点检测，没有在完整寿命轨迹上定位退化起点，也不能排除稀少但重要的拐点被抹平。因此当前不支持仅凭现有现象优先采用针对突变的原型引导。

## 3. 跨通道关系

**[Observed]** 在每个窗口内减去各通道时间均值后计算相关矩阵，减少窗口间寿命/均值变化的混入；再计算一阶差分的相关矩阵，以及−2/−1/0/+1/+2步差分时滞相关。对91个通道对取绝对差均值。

| 数据集 | 窗口内相关误差：生成/真实参照 | 差分相关误差：生成/真实参照 | 时滞相关误差：生成/真实参照 |
|---|---:|---:|---:|
| FD001 | 0.041 / 0.023 | 0.022 / 0.027 | 0.021 / 0.026 |
| FD002 | 0.004 / 0.002 | 0.005 / 0.004 | 0.012 / 0.013 |
| FD003 | 0.048 / 0.045 | 0.036 / 0.034 | 0.025 / 0.028 |
| FD004 | 0.005 / 0.002 | 0.005 / 0.004 | 0.012 / 0.011 |

- **[Observed]** 整体差分/短时滞相关误差大多与真实发动机参照同量级，没有普遍多传感器失步的强证据。
- **[Observed]** FD003存在值得单独检查的局部通道对：RUL91–124的s8/s13差分相关绝对误差平均0.342，但同一通道对真实A/B参照也达到0.266，且不同发动机划分波动很大。不能只截取最差通道对认定生成器破坏了同步性。
- **[Observed]** 线性相关仅覆盖二阶关系；不检验非线性依赖、物理守恒或长于2周期的对齐。不能据此宣布所有跨通道机制正确。

## 4. 不同RUL条件是否都生成相似信号

**[Observed]** 对每个区间计算14维传感器窗口均值中心；比较10个区间对的中心距离。下表用所有区间对的距离求和后取“生成/真实A”比值，避免极小真实距离导致单个比值支配平均。方向余弦按真实区间距离加权。这里衡量的是跨窗口、跨RUL的条件分离，不是同一虚拟发动机的退化轨迹。

| 数据集 | 条件间距离比：生成/真实A | 真实B/真实A参照 | 变化方向余弦：生成/参照 |
|---|---:|---:|---:|
| FD001 | 1.355 | 1.027 | 0.982 / 0.997 |
| FD002 | 1.807 | 1.140 | 0.715 / 0.682 |
| FD003 | 1.342 | 1.034 | 0.949 / 0.978 |
| FD004 | 1.668 | 0.957 | 0.911 / 0.892 |

- **[Observed]** 在传感器均值特征上，条件差异没有塌缩为0，反而平均被放大至真实的约1.34–1.81倍。图中的多个传感器呈现趋势方向大体正确、幅度或偏移不准确的模式。
- **[Observed]** FD001/FD003变化方向较一致；FD002的真实参照方向本身也波动明显。不能把这一汇总直接解释成“条件太强”，也不能据此推断简单提高/降低guidance就能改善预测。
- **[Hypothesis]** 比“RUL条件没起作用”更符合本次描述的是“给定RUL时所生成的信号分布不够准确”。支持：同RUL水平分布偏移及条件间距放大；反向/限制：未匹配运行工况/故障类型，均值特征不能代表全分布，也没有干预检验因果。下一步若继续，应先结合真实训练基线逐样本预测，定位这些偏移是否与误差相联系，不能直接启动条件增强训练。

## 与四个修改方向的对应

| 修改依据 | 本轮证据 | 判断 |
|---|---|---|
| 严重过平滑，需要原型引导 | 平均差分幅度接近真实，高频占比无统一下降 | 暂不支持作为首要方向；稀有事件仍未检验 |
| 多传感器不同步，需要跨通道修复 | 总体线性/短时滞关系接近真实参照，局部FD003有差异 | 不支持普遍失步结论，局部问题可保留 |
| 条件不生效，需要加强RUL条件 | 均值条件分离未消失，反而偏大 | 不支持直接增强条件；应先检查条件分布准确性 |
| 合成数据没有补充有效信息 | 先前真实/合成训练差距存在，但未做真实+合成增强 | 预测效用不足仍成立，增强价值未检验 |

## 审计、限制与停止决定

- **[Observed]** 全部4数据集×5种子×5区间完成；每组600窗口、匹配标签相同；20份生成数据与实际源数据绑定SHA-256。输入、抽样索引、完整传感器和通道对指标均保留。CPU运行，无新训练、无测试集参数选择。
- **[Observed]** 同一发动机的滑动窗口高度重叠，不将600窗口当作600个独立发动机，不使用窗口级p值。图中阴影为5个种子/真实划分的min–max，不是置信区间。
- **[Observed]** 本轮是支持性诊断，非论文新指标的严格数值复现；论文对应目标、差距、超出论文种子变化、对论文结论的影响均不可直接判定。严格TableI/V/VI历史结论保持不变。
- **[Observed]** H-smooth严重整体过平滑、H-sync普遍线性失步、H-collapse均值条件塌缩，在本次诊断中均缺乏支持；只有一次非干预检查，未达到“两次独立最小实验否定”的停止阈值。没有自动安排进一步实验或扩展。
- **[Hypothesis] 建议下一步**：把同RUL条件下的生成/真实信号偏移与真实训练预测器对合成样本的寿命预测做一致性核对；只读诊断优先于重新训练。原型引导、重采样和条件增强都没有被本轮证据直接选为必要修改。
