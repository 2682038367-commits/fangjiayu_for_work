## 共性与局部错误

- [Observed] 0-30：3/23/33共同额外报高且额外出错34/61台；并非只是在原有真实预测器的共同高估基础上重复同一误差。seed23为61/61台都更高且更差，最大5台只占正D总量13.8%，错误分散。seed43有46/61台D>0，最大5台占35.7%，也不能概括为只有少数异常。其A/D同时>0的43台全部与seed23重合。
- [Observed] 31-60：3/23/33共同A/D均>0只有2/41台（109、179）；seed3和33的平均D分别−297.30/−46.40，整体是改善，因此不能将此段当作三者共有的生成新增退化。23和43的平均D分别+196.71/+300.53，A/D均>0的病例有17台重合。
- [Observed] 43的31-60段25/41台D>0，但最大的5台占正D总量67.7%；这5台为179、15、253、109、68。68的A为负而D为正，说明新增错误也包含比参照报得更低，不能全部归为额外高估。0-30段43的增量既广泛又有较重尾部；两段需要分开。
- [Observed] 13在0-30有34台D>0但平均D为−49.48，说明其他发动机上的改善抵消了退步；不能仅看“出错台数”就判断总体变差。正增量、负增量及净和全部保留。
- [Code] 集中度分母为Σmax(D_i,0)，负D改善不进入分母。上述比例不是正误差对净退步的因果贡献，也不把25预测器当25次独立生成器训练。方向计数按严格>0，仅作描述，不作显著性判断。
- [Hypothesis] 优先可回训练/dev检查0-30中多生成器共同新增错误对应的信号模式；31-60要区分23/43的退化与3/33的改善。既有末端信号偏移继续保留为43局部线索，不能推广成全部FD002共同原因。该配对不证明原因位于信号、标签、生成器或预测器某个单一环节，不据测试病例直接选模型/轮次。
