日期：2026-10-22。诊断 Run ID：`diagnostic-rul-segment-w48-20261022`。

## 问题与结论

**[Hypothesis]** FD003/FD004长剩余寿命窗口占比更大，可能使训练偏向该阶段，并导致低RUL区间预测质量下降。用户授权先用已有权重分段检查；本轮未运行采样权重干预。

**[Observed]** 数据不支持将FD003和FD004统一解释为“额外误差主要集中在RUL≤30”：FD003最大额外误差贡献来自31–60；FD004主要来自91–125，尤其125。该结果削弱了该假设的低RUL集中版本，但不能否定训练分布对性能存在其他影响。

## 口径与审计

- **[Observed]** 仅复用已有全数据w48下游LSTM权重，在原始真实测试集重新推理。130个模型：FD001/3/4各25个合成训练预测器，FD002为35个，以及每数据集5个真实训练基线。没有重新训练生成器、预测器或更改权重。
- **[Observed]** 130/130个模型的整体RMSE与已有CSV一致至CPU/GPU数值误差；最大绝对差0.0000092471，检查阈值0.001。逐样本预测与输入哈希已保存。
- **[Code]** 沿用相同真实数据预处理、测试窗口、末端RUL及125截断，每台测试发动机贡献1个末端窗口。分段按真实标签，绝不按模型预测分段。
- **[Observed]** 四数据集对比使用共同5个生成种子3/13/23/33/43，各配5个评估种子。FD002正式headline为7个生成种子，其全部结果另保留为`generated_headline`，没有替换冻结指标。真实训练基线为5个预测器。
- **[Observed]** 本报告展示 pooled RMSE = sqrt(各模型、该段所有测试样本平方误差的均值)，不是集成预测RMSE，也不是原报告“各模型RMSE的算术平均”。该口径允许按测试样本比例精确分解MSE；原口径也保存在CSV的mean_model_rmse字段。
- **[Observed]** 额外误差定义为“合成训练预测器MSE − 真实训练预测器MSE”，只衡量本地同协议差距。论文没有逐样本预测，不能将其称为相对论文的分段差距。真实训练基线也不是理论性能地板。

## 解释

- **[Observed] FD003**：RUL≤30的RMSE为16.318，对照9.030，存在明显额外误差；但它仅贡献总额外MSE的19.9%。31–60贡献50.7%；合计≤60贡献70.6%，该区间占测试发动机41%。因此可以说问题偏向寿命较低的一侧，但不是只集中在论文定义的疲劳阶段。
- **[Observed] FD004**：RUL≤30的RMSE为42.252，对照36.628，两者本身都较高，该段贡献28.3%。RUL=125单独贡献61.6%，91–124贡献25.4%，合计高RUL端贡献87.0%；31–90产生负贡献。125段有67台测试发动机，不是由极少数样本构成。
- **[Observed] FD004**：合成训练预测器在≤30段的平均误差(pred−true)为+36.208，而125段为−31.210；可描述为寿命两端向中间收缩的预测偏差。该现象不是生成器失效机制的因果证明。
- **[Observed] FD002**：共同5种子下，≤30占总额外MSE的47.9%。所以低RUL额外误差并不是FD003/FD004独有的特征。
- **[Observed] FD001**：主要额外误差来自61–124，≤30仅占5.3%。四数据集的阶段性模式不同。
- **[Hypothesis]** “相同125标签涵盖较宽传感器分布”“合成数据中条件与信号的一致性不足”“下游预测器对两端条件拟合不足”等可以解释部分现象，但本轮未做干预，不能据此归因于其中之一。RUL>30及125都不等价于已确认的无退化健康状态。

## 限制与下一步

- **[Observed]** 每个区间的独立测试单位是发动机，不是发动机数乘模型数；FD003各段只有15–22台发动机，模型共享同一测试集。本轮仅描述定位，未做区间显著性或因果检验。
- **[Observed]** 保存全部模型的分段误差、bias、MAE和每台发动机的预测，避免只凭总体均值判断。未改变测试集，也未用本轮测试结果选择新参数。
- **[Observed]** H-low（两者均以≤30额外误差为主）被本次分段定位削弱；这只是一次针对性检查，不满足“两次独立检验否定后停止”的阈值，也不需要追加训练来追求一致解释。H-distribution（分布构成有因果影响）仍未检验。
- **[Hypothesis] 建议**：先分别核对FD003的31–60及FD004的高RUL段中，合成信号与条件的一致性。当前证据不支持直接以“FD003/4都是疲劳样本比例不足”为已知原因开展统一平衡训练。若后续用户选择因果对照，需单独冻结设计，保证模型/种子/总更新步数/生成标签分布/下游协议不变，只更改训练采样权重。该干预尚未执行；不把诊断结果并入论文严格复现结论。
