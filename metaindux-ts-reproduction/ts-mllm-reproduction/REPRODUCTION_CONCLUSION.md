# TS-MLLM 非官方复现 · 总结论

状态：**严格复现到此停止**。不再对 TMAF、prompt 或数据处理做任何调参或替代融合改造。

---

## 两条正式结论

1. **当前 `global_broadcast` 的均匀注意力是论文式 (13)–(19) 的字面数学结果，不是实现错误。**
   论文 III-D 明文把 `K_LLM、V_LLM` 定义为单个全局向量 `F_LLM` 沿时间轴复制 N 份，因此
   `softmax(Q_TS K_LLM^T/√Dk)` 的每个 Query 权重恒为 1/N。实现忠实复现了这一公式。

2. **因论文未公开 `F_LLM` 的归约方式，且行文与其公式存在内部矛盾，任何逐 token 交叉
   注意力、非广播融合或新池化策略都只能作为「改进实验」，不能写成论文复现。**

**因果归因的严谨性**：均匀注意力是「最强**候选**根因」，不是由消融直接证明的唯一因果
根因。即使 softmax 恒为 1/N，式 (18)/(19) 的门控仍可把同一 LLM 全局 value 以学习到的
权重注入各 patch（与时间无关、非选择性的混合）；确切缺失的是论文声称的「选择性检索」，
而非「多模态信息流整体为零」。

## 一、论文中明确且可操作的公开设定已忠实实现（未说明部分均标记为复现假设）

- 数据：FD001–004；14 有效传感器（删 1/5/6/10/16/18/19）；Min-Max（式 20）；窗口 40；
  RUL 上限 125。
- 时间分支：Patch 4 / Patch 步长 1；模型维 64 / 单头；可学习位置编码；`F_TS=Encoder(Z0)`（式 1/2）。
- 频谱：RP / STFT / CWT，114×114；视觉 128 维 MAE。
- 文本：96 维 DKE；最大 512 token。
- TMAF（式 13–19）：`Q_TS=F_TS W_Q`、`K_LLM=F_LLM W_K`、`V_LLM=F_LLM W_V`（广播）、
  `A=Softmax(Q_TS K_LLM^T/√Dk)`、`F_attn=A V_LLM`、`F_fused=Concat[F_TS,F_attn]W_out`
  （线性门、无 sigmoid）；Attention Key 64 / Output 32 / Fusion MLP 512 / Dropout 0.5；
  batch 128 / lr 0.002 / 30 epochs（表 II）。
- 指标：RMSE、Score（式 21/22）。

## 二、明确假设（论文未公开，逐项披露）

- 时间分支：2 层 Transformer、FFN 256、GELU、pre-norm、dropout 0.1；平均池化。
- `F_LLM` 归约 = 有效 token 的 masked mean（论文只给 `F_LLM=LLM(...)`，未说明归约方式）。
- 回归头：`mean pool → 64→512→GELU→Dropout0.5→1`（表 II 只明确 512/0.5）。
- 注意力 Value 维取 32（循表 II，与式 (16) 文字 `V∈R^{N×Dk}` 冲突）。
- Adam / MSE；按验证集选最优 checkpoint。
- 样本滑窗 stride 50（正文同时称扩充样本，存在叙述矛盾）、验证 stride 50。
- 测试取每发动机最后窗口、短轨迹左侧复制填充；评估 `clip[0,125]`（另存 raw）。
- Qwen3-0.6B 作主模型、冻结（表 III 的 Qwen3-0.6B 是 "One Fits All" 对照，非主模型型号）。
- 线性视觉 projector（128→1024）、96 维 DKE→线性桥接；对齐目标为 projector 对 teacher
  embedding 的 MSE。
- 本地小 MAE（patch19/2 层/4 头/15 轮/mask0.75）与预训练日程。
- 专家知识/统计 prompt 的具体内容、阈值与传感器选择。
- FD002/FD004 按工况 Min-Max（文献支持的补充预处理，非原文明文方法）。
- 目标尺度 B = RUL/125（用户选择的训练目标假设）。

### 三·附：batch128 vs batch32 —— 必须在同一归一化下比较

此前报告曾把「batch128 时间基线崩成 43–44」归因于 batch size，实为**归一化混淆**：
那些 43–44 是**旧全局 Min-Max** 下 FD002/FD004 的退化结果（接近常数）。当前协议
FD002/FD004 已改用按工况 Min-Max。对齐归一化后，各结果如下（测试 RMSE，cycle）：

**时间基线（纯时间模型）：**

| 子集 | 归一化 | batch128 | batch32 |
|---|---:|---:|---:|
| FD001 | 全局 Min-Max | 21.54 | 18.10 |
| FD002 | 按工况 Min-Max | 18.72 | 17.15 |
| FD003 | 全局 Min-Max | 34.67 | 19.41 |
| FD004 | 按工况 Min-Max | 20.78 | 18.85 |

（旧全局 Min-Max 下 FD002/FD004 时间基线曾退化到 43.90/44.77，见
`FOUR_SUBSET_MULTIMODAL_RESULTS.md`，已被上表按工况值取代。）

**完整 TMAF（全模态）：**

| 子集 | 归一化 | batch128 | batch32（3 seed 均值） |
|---|---:|---:|---:|
| FD001 | 全局 Min-Max | 16.32 | 17.23 |
| FD002 | 按工况 Min-Max | 17.09 | 17.09 |
| FD003 | 全局 Min-Max | 23.43 | 21.51 |
| FD004 | 按工况 Min-Max | 19.00 | 18.38 |

**结论：**

1. 「batch128 崩成 43–44」仅发生在**旧全局 Min-Max** 的 FD002/FD004；改用按工况
   Min-Max 后 batch128 时间基线不崩（18.72/20.78），batch32 略优 1.5–2。
2. 完整 TMAF 对 batch size **不敏感**（同一归一化下两 batch 相差 < 2）。
3. **归一化的影响 > batch size 的影响。** 把旧全局归一化结果与当前按工况结果混在一起，
   是此前「batch128 全崩」误读的来源。
4. FD001/FD003 为单工况、仍用全局 Min-Max；其 batch128 时间基线偏低（21.54/34.67）
   属**样本少（仅 90 次更新）**的独立问题，batch32 增到 18.10/19.41 才恢复。

## 四、Fig. 6 未复现

四子集验证 RMSE 均值下，**完整多模态模型在任何一个子集上都没有相对单模态消融的稳定
优势**：FD002/FD003/FD004 去掉一种模态反而更低；FD001 完整模型仅以 0.056 微弱占优，
远小于自身 seed 波动（0.278）。因此，在当前统一协议（batch32 + figure12_v1）和三个
随机种子下，**四个子集均未复现** Fig. 6 的模态增益，该结论不限于 FD003 特例，但同样
受限于这一实验范围。测试指标仅作描述性观察，不用于选模型。

## 六、停止理由

按论文已公开设定实现的 TMAF（广播单全局向量）在数学上退化为均匀注意力，无法实现论文
声称的「选择性检索」；而论文未公开 `F_LLM` 归约，且行文与公式矛盾，不存在「补上某一
明确步骤即可复现」的路径。继续调参或改造融合结构只会把架构假设混入「复现」结论，因此
严格复现到此为止。
