# FD001 纯时序 Patch Transformer 基线

## 固定配置

| 项目 | 设置 |
|---|---:|
| 输入窗口 | 40 × 14 |
| Patch 大小 / 步长 | 4 / 1 |
| Patch 数量 | 38（右侧复制填充 1 个时间步） |
| 模型维度 / 注意力头 | 64 / 1 |
| Transformer 层数 | 2 |
| 特征聚合 | Patch token 平均池化 |
| 回归头 | Linear(64, 1) |
| 优化器 / 损失 | Adam / MSE |
| Batch size / 学习率 | 128 / 0.002 |
| Epochs | 30 |
| 验证划分 | 按发动机 80/20，split seed 42 |
| Checkpoint | 验证集裁剪后 RMSE 最优 |

模型共 106,241 个可训练参数。测试指标使用裁剪到 `[0, 125]` 的预测，同时在
`result.json` 中保留未裁剪指标。

## FD001 结果

| 模型种子 | 最优 epoch | Val RMSE | Test RMSE | Test MAE | NASA Score | 预测标准差 |
|---:|---:|---:|---:|---:|---:|---:|
| 42 | 24 | 12.3749 | 13.0132 | 9.3954 | 336.51 | 42.4698 |
| 43 | 20 | 11.7804 | 13.0477 | 9.0733 | 318.73 | 40.7442 |
| 均值 | — | 12.0777 | 13.0304 | 9.2343 | 327.62 | 41.6070 |

两个模型种子的测试 RMSE 相差 0.0346，表明在固定发动机划分下结果稳定。预测标准差
约为 41，排除了输出退化为常数的情况。每次运行均输出恰好 100 个官方测试终点预测。

## 训练行为

- seed 42：训练 RMSE 从 77.60 降至 11.70，最优验证 RMSE 出现在 epoch 24；
- seed 43：训练 RMSE 从 77.15 降至 11.29，最优验证 RMSE 出现在 epoch 20；
- 训练与验证损失均显著下降，后期验证集在最优点附近正常波动；
- CPU 单次 30 epochs 约需 4.8–5.0 分钟。

## 产物

每个 `artifacts/temporal/FD001/seed*/` 目录包含：

- `best.pt`：验证集最优 checkpoint；
- `history.json`：30 个 epoch 的训练和验证记录；
- `result.json`：验证、测试及运行配置；
- `test_predictions.csv`：100 台测试发动机的真实值与预测值；
- `test_predictions.svg`：测试终点预测曲线；
- `scaler.json`：只在训练发动机上拟合的 Min-Max 参数。

注意：最初仅取验证发动机末端会使其标签全部为 0，不能用于 checkpoint 选择。当前
实现已经修正为使用验证发动机的全部滑动窗口；测试集仍严格保持每台发动机一个官方
终点预测。
